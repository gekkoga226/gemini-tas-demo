# Few-shot TAS ローカルモック — Round 18

標準作業のお手本と実作業動画を上下に表示し、Geminiの区間・ラベル候補を人が確認・修正するアプリです。既定は **明示的なモックモード**。再生可能な合成動画、標準セット、観察・候補・疑似使用量で操作できます。外部APIへは通信しません。

**モックの実装・ローカル検証と、実接続の運用成立・精度合格は別です。** 実API、精度、18〜22分性能、料金は未実測。全方式の適格性は `unverified` です。現行要件は [Few-shot仕様書 Round 18](docs/2026-09-06_FEWSHOT_SPEC.md)。着手順の例外とD1〜D10は [実装記録](docs/FEWSHOT_IMPLEMENTATION.md) に記録しています。

## 起動と主要操作

必要なもの：Node.js 20.11以上、FFmpeg / ffprobe。標準書PDFの検証にはPopplerの `pdfinfo` も必要です。追加のnpmパッケージ、認証情報、実評価動画はモック操作に不要です。

```powershell
cd C:/Users/mizuk/work/gemini-tas-demo
$env:MOCK_MODE = "true"
npm.cmd start
# npmの実行が制限される場合: node server.js
```

[ローカル画面を開く](http://127.0.0.1:4173/)

1. 「サンプルを設定」を押します。合成の標準24秒・実作業30秒の動画、語彙、標準記述2種類、代表画像12枚を作ります。
2. 標準セットの画像・記述・不足申告を確認し、「内容を確認して公開」を押します。
3. 同意欄を確認し、「お手本と照合／お手本なしで分析」と「分析方式」をそれぞれ選び、「解析を開始」を押します。
4. 上段の標準・下段の実作業を再生します。「区間同期」は同じJob No.の現在以降の区間（なければ先頭）へ移動します。外すと独立再生です。対応がなければメッセージを表示します。
5. タイムラインや区間一覧から区間を選び、候補・根拠・生の確信度・警告を確認します。時刻は人の修正として編集できます。ラベルは語彙から選びます。追加・削除・Undo・Redoも使えます。
6. 入力中は「区間に未反映」、区間への反映後は「履歴に未保存」と表示します。「修正を履歴に保存」「確認済みJSONを保存」は入力途中の内容も検証して反映します。不正な入力は消さず修正を求めます。確認済みJSONには修正区間とAI原本JSONを分けて同梱し、モック表示・方式・版・ハッシュ・共有元・元候補・根拠を追跡できます。
7. 方式やお手本の有無を変え、「同じ区間でラベルを再判定」。案1と案3は同一Stage1を使い、案2は別Stage1です。条件が変わった場合は「区間分割から再分析」に切り替わります。

MP4は入力欄から登録できます。「標準セットを作成・確認」では、登録済み標準動画、作成専用GT JSON、確認済み語彙を選んで新セットを作成します。PDFからの語彙抽出は非同期で行い、生成JSONを人が修正・確認して登録します。識別条件は標準書・開発用資料から作り、実評価GTから作成しません。

ブラウザを閉じてもサーバーの処理は続きます。明示的に止める場合は「中止」。サーバー停止後の未完了処理は再起動時に中断として記録し、履歴の「再試行」で新runを作ります。受付済みジョブは再開します。終了は起動したターミナルで Ctrl+C です。

## 方式と保存

| 方式 | Stage1 | Stage2 |
|---|---|---|
| text_only（案1） | 語彙を含めず観察・分割 | 文章・語彙・識別条件 |
| vocabulary_guided（案2） | 語彙・識別条件を追加。最終ラベル禁止 | 文章・語彙・識別条件 |
| visual_evidence（案3） | 案1と同じ実artifact | 案1の入力＋実動画1本。Fewのみ標準代表画像 |

Fewは対応profileの標準記述を追加し、Zeroは追加しません。Stage2は全方式でIDだけを返し、時刻変更を拒否します。GT原本・表示用標準工程列・採点情報は通常入力へ渡しません。

`data/` に媒体原本、標準セット、GT作成入力、語彙、Stage1実体、方式別キャッシュ参照、ジョブ、全送信本文・生応答、修正履歴、削除台帳を保存します。アクセストークンは保存しません。推論原本・公開セットは不変、修正は別履歴です。旧9項目は画面用アダプターで、新しい結果契約から分離しています。

## 設定

| 環境変数 | 用途・既定 |
|---|---|
| MOCK_MODE | true。実接続は明示的にfalse |
| PORT / DATA_ROOT | 4173 / data。同じDATA_ROOTを複数サーバーで共有不可 |
| FFMPEG_PATH / FFPROBE_PATH / PDFINFO_PATH | 各実行ファイルの場所。未指定はPATH |
| MAX_UPLOAD_BYTES / MIN_FREE_BYTES | モックは2GiB / 256MiB。実接続では明示必須 |
| MOCK_DELAY_MS | モック1呼び出しの待機時間。故障・中断の操作確認に利用 |
| ENABLE_MOCK_FAULTS | trueで検証用faults入力を許可。モック専用 |
| GEAP_TIMEOUT_MS / JOB_TIMEOUT_MS | 1 API 60分 / ジョブ3時間。人の承認待ちは除外 |
| GEAP_PRICE_TABLE | 確認済み料金表JSON。未指定・使用量内訳不足は費用null |

空の実接続用保存先からの合成入力準備は [接続ガイド](docs/PRODUCTION_CONNECTIVITY_GUIDE.html) を参照してください。`data-real/` と `connectivity-inputs/` もGit除外対象です。

実接続の認証・媒体回収・高度な再実行は [運用手順](docs/FEWSHOT_OPERATIONS.md) を参照してください。実接続失敗をモック成功へ置き換える処理はありません。Cloud Runは必須ではなく、今回デプロイはしていません。

## 検証

```powershell
npm.cmd test
npm.cmd run probe:self-test
```

全テストは外部API不要です。実API用アダプターのテストも通信を置き換えています。プローブ自己検査は合成データのCheck 7〜11、ジョブ故障経路、採点の手計算例を実行し、実測Checkの状態を変更しません。

実測の入力・実行方法・未確認事項は [GEAPプローブ](tools/geap-probe/README.md)。旧MVP資料・旧Flashテキスト疎通テストは歴史的互換検証として残しています。画面は新しい永続ジョブAPIだけを使い、旧 `/api/analyze` の実接続は通常起動では廃止しています。
