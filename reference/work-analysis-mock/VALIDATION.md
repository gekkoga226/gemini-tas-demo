# 検証記録

確認日：2026-09-11

## 実施済み

- Node.jsのテスト8件が成功。
- 80分・120分・短尺のサンプルで、全区間の合計が動画時間と一致。
- Zero-shotとFew-shotで観察順・時刻は同一、標準照合の結果は独立して保持。
- JSON保存・読込のデータ往復が一致。
- 区間の抜け・重複・逆転・未定義標準ID・不正な判定値を拒否。
- 境界の修正が隣接区間へ反映され、再確認が必要な区間が未確認になる。
- 無効な修正を拒否した後も元データを維持。
- 一方式だけの結果を受理し、両方式なしを拒否。
- CSV内の式として解釈され得る文字列を処理。
- JavaScript構文、Python構文、HTMLの重複ID、画面要素への参照を確認。
- 単体HTMLに外部スクリプト・CSS・画像の参照がないことを確認。
