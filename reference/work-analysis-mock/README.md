# 作業みえる：ローカル検証モック

動画を読み込み、作業区間・標準との比較・3種類の時間分析・行動者ベースの実施手順書を確認できます。

## すぐに開く

ZIPを展開し、`work_analysis_mock.html`をChromeまたはEdgeで開いてください。インストールやAPIキーは不要です。ファイル選択、動画再生、JSON読込・保存、CSV出力はブラウザで動作します。

Windowsでローカルサーバーを使う場合は、Python 3を用意して`start-local.bat`を実行し、表示される`http://127.0.0.1:8080/`へアクセスしてください。コマンドなら`python server.py`です。終了はCtrl+C。

## 試す順番

1. 最初は架空の120分サンプルを表示しています。「見本なし／見本あり」を切り替えます。
2. 「対象動画を選ぶ」で手元の動画を開きます。以前の結果は解除されます。
3. 「操作用サンプルを表示」を押すと、動画の長さに合わせた架空の結果を表示します。
4. 区間を選び、再生位置の移動、観察内容、標準書との対応を確認します。
5. 「区間・対応を修正」で開始終了の秒数、標準対応、確認状態を変更できます。
6. 「標準との比較」「時間の分析」「実施手順書」で結果の見方を確認します。
7. 「結果を保存」でJSON、「CSV出力」で選択中方式の区間表を保存します。
8. JSONを再読込すると、修正した結果を再現できます。

## 分析結果について

このモックはGemini未接続です。動画の内容を解析せず、サンプルの作業名や数値は架空です。動画を選んだだけで実際の分析結果が出るアプリではありません。

見本動画の選択は登録操作の体験です。正解ラベルとの結合、標準書PDFの解釈、GeminiのFew-shot実行は次段階で接続します。

実際の結果がある場合は、`examples/result-format-example.json`と同じ形式へ変換して読み込めます。区間データは先頭から末尾まで連続させ、動画名・長さ・容量を合わせてください。現在のサンプルをJSON保存すれば、手元動画に合った形式のひな型も作れます。サンプルを実測値と偽って扱わないでください。

修正はメモリ内にあります。閉じる前にJSONを保存してください。動画の外部送信・ブラウザへの永続保存はしません。サンプルの2方式の違いは、実際の精度差を示しません。

## ファイル

- `specification.md`：今回の仕様書。モック・ローカル実分析・Cloud Run共有版の範囲を定義。
- `work_analysis_mock.html`：単体で開けるモック。
- `dist/index.html / styles.css / core.js / app.js`：編集用ソース。
- `server.py / start-local.bat`：ローカル起動。
- `Dockerfile / .dockerignore`：静的モック配信用コンテナ定義。
- `examples/result-format-example.json`：読込形式のサンプル。架空データ。
- `tests/core.test.cjs`：区間・集計・JSON・修正の確認。
- `VALIDATION.md`：実施した検証と残る確認事項。

HTMLを再生成する場合は`python build_standalone.py`。計算処理のテストはNode.jsで`node --test tests/core.test.cjs`。

## Cloud Runへ進めるとき

静的モックは同梱Dockerfileでコンテナ化できるようにしています。ビルド・デプロイは今回実施していません。

実分析版は仕様書に従い、FastAPI、Gemini接続、Cloud Storage、Cloud Run Jobs、共有DB、社内認証を追加します。`server.py`はモック配信用であり、本番の長時間分析や認証を提供しません。コンテナ内のファイルを正式な保存先にしないでください。

仕様の出典・処理条件は、前段のGCP Gemini TAS提案資料を参照してください。
