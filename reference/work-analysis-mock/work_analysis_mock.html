このモックの使い方

  1. 「対象動画を選ぶ」で動画を開きます。
  2. 「操作用サンプルを表示」で2方式の見え方を体験します。
  3. 区間を選ぶと動画がその位置へ移動します。
  4. 実際の結果は、仕様書の形式にそろえたJSONで読み込めます。
  5. 修正後は「結果を保存」。閉じると未保存の変更は消えます。

見本なし／見本ありとは？

Zero-shotは正解付き動画例を使わず、Few-shotは正解付き標準動画を見本にして照合する方式です。今回のモックはGemini未接続です。見本動画の選択も登録操作の体験で、分析には使われません。

「標準作業」は標準との対応を示し、人の確認済みを意味しません。「未記載」も直ちにムダとは判断しません。
