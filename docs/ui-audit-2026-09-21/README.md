# Ollo公開UIを参考にした改善モック

作成：2026-09-22（JST）。フォルダ名は監査着手日の2026-09-21です。

[画面一覧を開く](index.html) ／ [監査レポート](../2026-09-22_OLLO_UI_AUDIT.md)

本リポジトリの「作業みえる」に対する独立したデザイン提案です。Ollo Factoryの実製品でも、本体アプリの修正版でもありません。動画・工程・時間差はすべて架空です。本体の実装・API・データは変更していません。

## 開き方

`index.html` をブラウザで開けます。画面切替、デスクトップ／768px／390pxの表示切替があります。ブラウザによってローカルファイル内のiframe制限がある場合は、以下のローカルプレビューを使用してください。

```powershell
node docs/ui-audit-2026-09-21/preview.mjs
```

[ローカルプレビュー](http://127.0.0.1:4176/)（サーバー起動中のみ）。`127.0.0.1` だけで待ち受け、外部公開しません。終了は起動したターミナルでCtrl+Cです。

## 試せる操作

- 開始画面の「架空の動画で試す」→作業名一覧またはお手本選択→同意→開始。モードを往復しても同じ画面内の入力は保持します。
- 処理画面下部で状態を選ぶか「次の工程へ」を押し、通信断・失敗・中止・完了を表示できます。実処理の待機時間を再現するものではありません。
- 結果の工程一覧・時間軸を選ぶと、その工程の模式映像と根拠へ移動します。「工程位置を連動」は対応工程への移動です。両動画の同時再生ではなく、片方ずつ再生するモックです。
- 再生ボタンとシークバー、作業区間／時間内訳／実施手順書の切替、未確認絞込み、確認済み、確認メモを操作できます。
- 「確認内容を保存」は架空の確認メモ・確認状態をJSONでダウンロードします。本体への保存ではありません。
- ライブラリの確認待ちセットを選び、確認チェック後に公開済みの表示を試せます。実際の登録機能は含めていません。

## 意図と制限

Olloの公開画面で確認した、動画を主領域、タイムラインを直下、詳細・一覧を右側に置く構造に寄せています。白と青、細い区切り、密度のある一覧を使っています。Olloのロゴ・画面画像・コピーは使用せず、独自のSVG模式映像をコードで描画しています。外部フォント・CDN・分析API・リモート動画は使用しません。

ローカルファイル選択はファイル名を表示するだけです。動画は送信・保存・再生しません。選択したファイルの中身を模式映像に差し替えたと誤解しないよう、画面に操作デモと明記しています。ページ遷移・再読み込み後は架空の固定サンプルに戻ります。送信条件の詳細設定もAPIへ接続しません。

スマホ表示はiframeの内容領域を390 CSS pxにしたレスポンシブ確認です。Windowsのスクロールバーを除く本文幅は375pxでした。実端末・タッチ操作・OSキーボードの検証ではありません。デスクトップの横並びをそのまま縮めず、映像を切替表示します。時間軸とナビは必要に応じて内部だけ横スクロールします。
