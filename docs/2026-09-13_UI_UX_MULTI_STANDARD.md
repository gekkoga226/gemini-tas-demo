## 公開情報から参考にした操作原則

2026-09-13に [Ollo Factory製品紹介](https://ollo.jp/ollo-factory) と [比較分析紹介](https://ollo.jp/ollo-factory/work-comparison) を参照。公開ページ内の画面画像もブラウザで確認した。ログイン後の実製品操作を検証したものではない。

- 動画を出発点にする：ホームの主操作を「新しい分析」にし、動画選択から開始までの順番を示す。
- 同じ工程を映像と数値で確かめる：公開画面は二つの動画と時間差グラフを近接して配置している。本実装では山積み表・時間分布・左右比較を同じ閲覧領域に置き、工程から出典映像へ戻れるようにする。
- 時間の違いを判断材料にする：合計だけでなく、工程ごとのばらつき、区間数、欠けている工程を表示する。
- 現場の言葉を主にする：開始条件・処理中・確認待ち・完了と次の操作を明記し、技術的な設定は必要時に開く。

上記は公開情報から抽出した設計上の解釈。画面の意匠、画像、文面はコピーしていない。同社が公表する精度・導入効果を本アプリの性能として使用しない。

## 変更

- ホーム：新しい分析とお手本ライブラリへの主導線。再生用動画の選択と分析開始を区別。
- 分析画面：入力と開始条件を二列で表示。送信先、同意、開始ボタンをデスクトップの初期画面内に配置。狭い画面は開始欄へのリンクを最初に表示。選択中の動画名を統一。処理状態と媒体回収を別表示。
- お手本：複数の動画と各GTを登録。区間の入力表または作成専用GT JSONを利用。記述・画像・出典を動画ごとに確認して公開。
- 可視化：お手本の区間別時間分布、動画別の工程合計の山積み表、左右の動画比較。合計時間はサイクル数の差にも影響されるため区間数を併記。
- 保存：新規配列入力はstandard-set.v2。既存v1の読込と単一動画APIを維持。通常分析のexample-view.v2はGT・出典・お手本時刻を除く。プロンプト本文・凍結原本・manifestは変更しない。
