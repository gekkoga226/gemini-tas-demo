    このモックについて

    • 架空のデータで作った画面です。サーバーには接続せず、分析も行いません。保存した内容は、このブラウザの中だけに残ります。
    • 映像は模式映像で、実際の作業映像ではありません。
    • お手本の区間は、公開済みお手本セットの表示用区間です。対象動画の正解データは表示しません。
    • 直した内容は「修正後」として別に残し、自動判定は変えません。
    • 決めてほしいこと：① 時間バーの並べ方の初期表示（いまは「0秒をそろえる」）、② 時間差の元データの初期表示（いまは「自動判定」）。
