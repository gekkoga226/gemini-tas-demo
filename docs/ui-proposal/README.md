# UI改善提案モック

`public/` の実アプリに対する **UIレビューの改善提案** を、実際に操作できる形にしたものです。

> **実アプリのファイルは一切変更していません。** このフォルダーは独立した提案用モックで、
> 削除しても実アプリの動作に影響しません。

## 開き方

`workspace.html` をブラウザで **ダブルクリックするだけ** です。
サーバー起動もビルドも不要で、`file://` のまま動きます（外部CDN・フレームワーク不使用）。

```
docs/ui-proposal/workspace.html
```

編集内容は `localStorage` に保存されるので、リロードしても残ります。
元に戻すときは画面右上の **「初期状態に戻す」** を押してください。

## 何を触れば改善が伝わるか

| 操作 | 確認できる改善 |
|---|---|
| タイムラインの **区間の境目にカーソルを合わせてドラッグ** | 前後の区間が**連動**し、隙間も重複も発生しない（現行は重複エラーで巻き戻る） |
| ドラッグ中の**ツールチップ** | 確定前に「何秒になるか」「前後が何秒になるか」が分かる |
| **ズーム 1x → 4x** | 1xでは番号だけの区間が、拡大すると全文表示に切り替わる |
| **◆ をクリック**（3秒・5秒・4秒の区間） | 極短区間も選択できる（クリック領域を24px確保） |
| **Tabキーで境界ハンドルへ移動 → ← →** | キーボードだけで時刻を1秒ずつ調整できる（Shiftで5秒、Home/Endで可動端） |
| **「▮ 再生位置で分割」** | TASで最頻の「1区間を2つに割る」が1操作で完了する |
| **「区間を削除」** | 削除した時間を隣の区間が引き継ぎ、タイムラインに穴があかない |
| 何か編集したあと **「↶ 元に戻す (n)」** | Undoが20段まで積まれ、残段数が数字で見える |
| 編集フォームの各項目の下 | 「AI予測: ○○ から変更」と**元の値と差分**が常に見える |
| ヘッダーのバッジ | 「未確定の入力あり」「未ダウンロードの修正 N件」を**件数付き**で表示 |
| 右カラムを下までスクロール | 動画とタイムラインが**貼り付いたまま**残る |

## 検証

「読み込めた」ではなく、**実際にドラッグ・クリック・キー操作を駆動して**状態とDOMを検証しています。

```powershell
# jsdom を用意（リポジトリを汚したくない場合は別ディレクトリで）
npm i --no-save jsdom

# 1) スモークゲート：JSエラーなしで読み込めるか
node <skills>/building-operable-html-mocks/scripts/verify-mock.mjs docs/ui-proposal

# 2) 受け入れシナリオ：S1〜S10 ＋ A11y（57アサーション）
node docs/ui-proposal/scenarios.mjs
```

最終結果：

```
✓ workspace.html          … スモークゲート合格（JSエラー0）
57 passed, 0 failed       … 受け入れシナリオ全合格
```

## ファイル構成

```
docs/ui-proposal/
  index.html            workspace.html へのリダイレクト
  workspace.html        画面本体（コンテンツのみ）
  SPEC.md               設計スペックと受け入れシナリオ定義
  scenarios.mjs         受け入れシナリオの自動検証
  assets/
    style.css           デザインシステム（最小12px／白文字帯は全色4.5:1以上）
    data.js             SEED：10分・16区間（3秒/4秒/5秒の極短区間を含む）
    store.js            SEED＋localStorage差分。Undo/Redoスタック（20段）
    shell.js            時刻フォーマット、目盛り刻み算出、トースト、モーダル
    scene.js            canvasによる疑似映像（timeから決定的に描画）
    timeline.js         タイムライン本体（目盛り／2レーン／境界リップル編集）
    app.js              一覧・編集フォーム・JSON出力・ショートカット
```

## このモックで検証していないこと

- 解析前・解析中の画面（今回はタイムライン中心の1画面に絞ったため）
- 実MP4の再生（`<video>` ではなく canvas の疑似映像）
- 実際のJSON出力先やファイル名規約（ダウンロード自体は動きます）
