# 動画分析とお手本の操作

トップの `/` は `/analysis.html?new=1` に進みます。このページは動画分析とお手本ライブラリの操作を説明します。従来のレビュー画面は `/review.html` にあり、操作は [作業レビュー画面](WORK_REVIEW_REBUILD.md#画面と使い方) を参照してください。

起動・必要ツールは [運用手順](FEWSHOT_OPERATIONS.md) の「ローカル起動と保存」を参照。実接続時は [接続ガイド](PRODUCTION_CONNECTIVITY_GUIDE.html) を使用する。

1. 「新しい動画を登録」でMP4を選ぶか、「登録済み動画から選ぶ」で対象を選択します。「選択中」に動画名と長さが表示されます。
2. 「お手本と照合」では公開済みの標準セットを選びます。「お手本なしで分析」ではお手本動画は不要で、確認済みの作業名一覧を選びます。「お手本と照合」でセットを選んでいた場合は、そのセットの作業名一覧を使い、選択欄に「〇〇の作業名一覧を使用」と表示します。再読み込みや実行履歴から結果を開いたときも、使った作業名一覧を選択欄に戻します。
3. 分析方式を選び、右側の送信先・開始条件・作業者の同意を確認して開始します。完了後は「未確認区間から結果を見る」から映像と結果を確認します。モック表示の場合は外部通信を行わず合成結果になり、結果の見出しにも「合成モックの結果」と表示します。
4. 上段の標準・下段の実作業を再生します。「区間同期」は同じJob No.の現在以降の区間（なければ先頭）へ移動します。外すと独立再生です。対応がなければメッセージを表示します。
5. タイムラインや区間一覧から区間を選び、候補・根拠・生の確信度・警告を確認します。時刻は人の修正として編集できます。ラベルは語彙から選びます。追加・削除・Undo・Redoも使えます。
6. 入力中は「区間に未反映」、区間への反映後は「履歴に未保存」と表示します。「修正を履歴に保存」「確認済みJSONを保存」は入力途中の内容も検証して反映します。保存するたびに、メモ（任意・1,000文字まで）を1件付けられます。保存の一覧には、日時・確認者・メモを新しい順に表示します。不正な入力は消さず修正を求めます。確認済みJSONには修正区間とAI原本JSONを分けて同梱し、モック表示・方式・版・ハッシュ・共有元・元候補・根拠を追跡できます。
7. 方式やお手本の有無を変え、「同じ区間でラベルを再判定」。案1と案3は同一Stage1を使い、案2は別Stage1です。条件が変わった場合は「区間分割から再分析」に切り替わります。

## お手本を複数登録する

1. 「お手本ライブラリ」→「新しいセットを作る」を開き、セット名と確認済みの作業名一覧を選びます。
2. お手本動画を登録または選択し、名前と正解が確認された区間を入力します。「最後の区間を分ける」で行を増やし、開始・終了・作業名を調整します。0秒から動画末尾まで隙間なく入力してください。動画IDと長さが一致する作成専用GT JSONも読み込めます。
3. 「お手本動画を追加」で必要な本数だけ繰り返します。同じ内容の動画は重複登録できません。全動画の送信同意と送信先を確認して「お手本セットを生成」を押します。
4. 「内容の確認待ち」になったら各お手本を開き、記述・不足申告・代表画像と出典を確認します。確認欄にチェックを入れ、「確認したセットを公開」を押します。
5. 山積み表は動画ごとの工程合計、分布は各お手本区間の所要時間です。点や棒を押すと出典の映像へ移動します。左右比較の差は「右 − 左」。ない工程は「該当なし」で、ゼロ秒の標本にはしません。

PDFからの語彙抽出はライブラリ下部から行い、生成JSONを人が修正・確認して登録します。識別条件は標準書・開発用資料から作り、実評価GTから作成しません。

## 合成サンプルで試す

モック起動で「合成サンプルで試す」を押すと、標準24秒・実作業30秒の動画、語彙、標準記述2種類、代表画像12枚を用意します。お手本の内容を確認して公開後、上記の分析操作を試せます。合成模様と人工的な作業名は操作検証専用で、実業務の精度を示しません。

## 中止・再試行と保存

処理状況は入力の下に表示されます。完了・失敗・中止後に「処理中」とは表示しません。一時媒体の回収状態は別欄で確認します。失敗・中止したお手本も、完了済みの記述や画像、試行履歴は残ります。

ブラウザを閉じてもサーバーの処理は続きます。明示的に止める場合は「中止」。サーバー停止後の未完了処理は再起動時に中断として記録し、履歴の「再試行」で新runを作ります。受付済みジョブは再開します。終了は起動したターミナルで Ctrl+C です。

編集状態・確認済みJSONの保管の詳細は [運用手順](FEWSHOT_OPERATIONS.md) の「2026-09-08 レビュー修正後の操作・保管」を参照。
