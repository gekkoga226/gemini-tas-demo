# 動画分析とお手本の操作

トップの `/` は `/analysis.html?new=1` に進みます。このページは動画分析とお手本ライブラリの操作を説明します。旧 `/review.html` も新しい分析の入口へ転送します。旧画面の結果JSON読込・CSV・架空120分サンプルは終了しました（2026-10-03、段階5）。Bの合成サンプルとJSON書き出しは使えます。

起動・必要ツールは [運用手順](FEWSHOT_OPERATIONS.md) の「ローカル起動と保存」を参照。実接続時は [接続ガイド](PRODUCTION_CONNECTIVITY_GUIDE.html) を使用する。

画面の用語は [UI判断の決定記録](2026-09-27_UI_DECISIONS.md) 2章の用語表に合わせています。「自動判定」は分析で出た修正前の結果、「修正後」は人が直した結果（画面上の未保存の修正は表示中の説明に明記）、「対象動画」は分析する動画、「作業名一覧」は確認済みの作業名とST（作業標準書の時間）の一覧です。

上ナビで各節へ移動できます。入力・ライブラリ（開いた場合）・履歴・結果は縦に続く1ページです。ページの見出しは「作業の分析」で固定し、ブラウザの画面名は入口を選んだときに変わります。処理の完了や通常のスクロールでは変わりません。「使い方」から短い操作説明を開けます。720px以下では結果操作を縦に並べ、ライブラリの表は枠内を左右にスクロールできます。

## 一覧を準備せず、観察から分析して見本を作る

既定の「観察から作業内容を分析（一覧の準備不要）」は全体＋案1に対応します。作業名一覧・識別条件の登録、作成GTは不要です。

1. 動画Aを登録・選択し「お手本なしで分析」、動画全体＋案1を選びます。送信先と作業者の同意を確認して開始します。
2. 結果の手の動き・物体・位置・前後状態、仮名・作業内容・不足・根拠を映像で確認します。名前と説明は自由に入力できます。「観察記録を修正」では共通Observation JSONを編集できます。
3. 区間ごとに実際に確認した範囲をチェックし、確認者を入力して「レビューを保存」します。保存だけでは全項目を確認済みにしません。不正入力・未保存・保存失敗は表示され、入力は残ります。改名で区間出現IDは変わりません。
4. 「このレビューから見本を作成」で見本名・確認者と含める区間を選んで確定します。保存済みreviewの不変版だけを使います。区間・名称・作業内容・観察・根拠が未確認の例は確定できません。境界変更後は新しい区間に合う観察と人の根拠説明が必要です。
5. 「新しい分析」で別動画Bを選び「お手本と照合」、レビューから確定した見本を選択します。全体＋案1、送信先・同意を確認して開始します。Bの観察と仮名を先に保存し、対応候補・見本にない作業・対応不明を別に表示します。未対応の見本は欠落候補であり、欠落確定・0秒ではありません。
6. 保存した結果・reviewは実行履歴、見本はお手本ライブラリで再確認できます。後日Aをレビューしても既存見本版・Bの条件は変わりません。見本の観測時間をSTに換算しません。

モックの「合成サンプルで試す」はこの目的では語彙0件のA・Bだけを用意します。実映像の品質を表すデータではありません。詳しい適用範囲は[追加契約](2026-10-04_OBSERVATION_REVIEW_CYCLE_CONTRACT.md)。

## 確認済み一覧へ分類する従来方式

以下の従来操作は「確認済み一覧へ分類（従来方式・比較用）」を選んだ場合です。レビュー由来見本の新契約には適用しません。

1. 「新しい動画を登録」でMP4を選ぶか、「登録済み動画から選ぶ」で対象を選択します。「選択中」に動画名と長さが表示されます。
2. 「お手本と照合」では公開済みのお手本セットを選びます。「お手本なしで分析」ではお手本動画は不要で、確認済みの作業名一覧を選びます。「お手本と照合」でセットを選んでいた場合は、そのセットの作業名一覧を使い、選択欄に「〇〇の作業名一覧を使用」と表示します。再読み込みや実行履歴から結果を開いたときも、使った作業名一覧を選択欄に戻します。
3. 分析方式を選び、右側の送信先・開始条件・作業者の同意を確認して開始します。完了後は「要確認の区間から結果を見る」から結果画面へ進みます。モック表示の場合は外部通信を行わず合成結果になり、結果の見出しにも「合成モックの結果」と表示します。
4. 結果画面は、上に見出し（モード・お手本セットまたは作業名一覧・未保存の表示・保存）、中央に2つの動画（左＝お手本、右＝対象）、右に確認パネル、下に時間バーを並べます。1920×1080の画面（表示倍率100%）では1画面に収まります。幅1199px以下の狭い画面では、動画・時間バー・確認パネルの順に縦へ並び、Tabキーの順も見た目の上から下になります。見出しの「要確認 N区間から見る」を押すと、狭い画面では編集欄が見える位置まで移動して、作業名の欄に焦点が入ります（「自動判定」表示のときは、選んだ行に焦点が入ります）。「区間同期」は、片方の動画で工程が変わると、もう片方を同じ作業名の区間（現在以降の最初の区間、なければ先頭）へ移動します。外すと独立再生です。対応がなければ「対応区間なし」と表示します。
5. 時間バーは上段がお手本、下段が対象で、同じ作業名の区間を帯でつなぎます。横軸は実時間です。「0秒をそろえる」（初期表示）と「選んだ工程で頭をそろえる」を切り替えられ、どちらでも1秒あたりの幅は変わりません。赤い線が再生位置、青い枠が選択中、破線の枠が選んだ区間と対になるお手本の区間、区間の上端の線が要確認、点線が自動判定の境目、破線の区間が作業外です。同じ作業が繰り返すとき、帯は回数どうし（お手本の1回目と対象の1回目）で結び、区間同期や「時間差」の行を押したときの移動は、今の位置以降の最初の同じ作業へ移ります。時間バーはTabキーで「対象動画の再生位置」の目盛りの行に移り、←→キーで再生位置を1秒ずつ（Shiftを押しながらで5秒ずつ）動かせます。
6. 確認パネルの「時間差」タブは、工程ごとにお手本と対象の合計時間と差（対象−お手本）を、差の大きい順に並べます。元データは「自動判定」（初期表示）と「修正後」を切り替えられ、表示中の元データを常に表示します。お手本にない工程は「該当なし」で、差は「—」です。行を選ぶと、両方の動画がその工程の区間へ移動します。
7. 「区間」タブでは、上に編集欄、下に一覧（「要確認だけ」／「すべて」）を置きます。「要確認だけ」の一覧は、結果を開いたとき、「要確認だけ」を押したとき、「修正後」「自動判定」を切り替えたときに、要確認の区間と選んでいる区間で組み直します。そのあとは行を押しても行は増えも減りもせず、押した行は動きません（直して要確認でなくなった行も、組み直すまで残ります）。時間バーで一覧にない区間を選ぶと、その区間の行だけが加わります。一覧から区間を選び、編集欄で開始・終了・作業名を直して「この区間に反映」を押します。「区間」タブの「要確認 7」のような数字は、要確認の区間の数です（区間の総数ではありません）。作業名は作業名一覧から選びます。時間バーでは、選んだ区間の両端の取っ手をドラッグするか、取っ手を選んで←→キーで1秒ずつ動かせます。「＋ 区間を追加」「区間を削除」「元に戻す」「やり直す」も使えます。「＋ 区間を追加」のダイアログでは、開始時刻・終了時刻・作業名（編集欄と同じ項目名）などを入力します。「自動判定」表示は修正前の結果を見るだけで、編集できません。候補・根拠・生の確信度は「根拠を見る」から開きます。
8. 入力中は「区間に未反映」、区間への反映後は「履歴に未保存」と表示します。メモだけを書いて保存していないときは「メモ未保存」と表示し、「実行履歴」から別の結果を開くとメモも自動で保存します。ページを閉じようとしたときは確認が出ます。上部の「保存」は修正を履歴に保存します（入力途中の内容も検証して反映します）。「区間」タブに入れた時刻が不正なまま別のタブで「保存」を押すと、保存は行わず「区間」タブへ戻り、直す欄を選んで理由を表示します。「メモ」タブでは、保存1回ごとのメモ（任意・1,000文字まで）と確認者を入力し、これまでの保存（日時・確認者・メモ）を新しい順に確認できます。ファイルへの書き出しも「メモ」タブの「自動判定JSON」「修正後JSON（保存して書き出す）」から行います。不正な入力は消さず修正を求めます。修正後JSONには修正区間と自動判定のJSON（推論原本）を分けて同梱し、モック表示・方式・版・ハッシュ・共有元・元候補・根拠を追跡できます。
9. お手本なしの結果は、動画1本・1段の時間バーと「STとの比較」タブを表示します。比較は自動判定が初期表示で、「修正後」に切り替えると時間バーと編集欄の元データもそろいます。繰り返しは平均が初期表示で、合計（ST×区間数と比較）・1回ごとも選べます。行を押すと表示中の元データの区間へ移動します。ST未登録・一覧外・作業以外は差を「—」にし、比較の合計から除きます。作業名一覧なしと全件ST未登録を別に説明し、比較できる作業が0件なら合計と差も「—」です。動画に出ない作業は0秒と扱わず別に示します。差から良し悪しを判断しません。「時間の分析を見る」は初め閉じ、開くと選んだ元データの合計時間・1回ごとの長さを表示します。「区間同期」は表示しません。お手本なしでも、お手本セットの作業名一覧を使った結果は、見出しの札を「作業名一覧：〇〇」にし、「お手本（動画・記述・画像）は分析に送っていません。作業名一覧だけを使っています。」と表示します（お手本を送った結果の札は「お手本セット：〇〇（N本）」です）。セットを使っていない結果には、札も一文も出ません。
10. 方式やお手本の有無を変え、「同じ区間でラベルを再判定」。案1と案3は同一Stage1を使い、案2は別Stage1です。条件が変わった場合は「区間分割から再分析」に切り替わります。

## お手本を複数登録する

1. 「お手本ライブラリ」→「新しいセットを作る」を開き、セット名と確認済みの作業名一覧を選びます。
2. お手本動画を登録または選択し、名前と正解が確認された区間を入力します。「最後の区間を分ける」で行を増やし、開始・終了・作業名を調整します。0秒から動画末尾まで隙間なく入力してください。動画IDと長さが一致する作成専用GT JSONも読み込めます。
3. 「お手本動画を追加」で必要な本数だけ繰り返します。同じ内容の動画は重複登録できません。全動画の送信同意と送信先を確認して「お手本セットを生成」を押します。
4. 「内容の確認待ち」になったら各お手本を開き、記述・不足申告・代表画像と出典を確認します。確認欄にチェックを入れ、「確認したセットを公開」を押します。
5. 山積み表は動画ごとの工程合計、分布は各お手本区間の所要時間です。点や棒を押すと出典の映像へ移動します。左右比較の差は「右 − 左」。ない工程は「該当なし」で、ゼロ秒の標本にはしません。

作業標準書PDFからの作業名一覧の抽出はライブラリ下部から行い、生成JSON（語彙・識別条件）を人が修正・確認して登録します。識別条件は作業標準書・開発用資料から作り、実評価GTから作成しません。

## 合成サンプルで試す

モック起動で「合成サンプルで試す」を押すと、お手本24秒・対象動画30秒の動画、作業名一覧、お手本の記述2種類、代表画像12枚を用意します。お手本の内容を確認して公開後、上記の分析操作を試せます。合成模様と人工的な作業名は操作検証専用で、実業務の精度を示しません。

## 中止・再試行と保存

処理状況は入力の下に表示されます。完了・失敗・中止後に「処理中」とは表示しません。一時媒体の回収状態は別欄で確認します。失敗・中止したお手本も、完了済みの記述や画像、試行履歴は残ります。

ブラウザを閉じてもサーバーの処理は続きます。明示的に止める場合は「中止」。サーバー停止後の未完了処理は再起動時に中断として記録し、実行履歴の「再試行」で新runを作ります。受付済みジョブは再開します。終了は起動したターミナルで Ctrl+C です。

編集状態・修正後JSONの保管の詳細は [運用手順](FEWSHOT_OPERATIONS.md) の「2026-09-08 レビュー修正後の操作・保管」を参照。
